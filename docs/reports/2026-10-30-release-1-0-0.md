# Release 1.0.0 (2026-10-30)

10 tickets, T-0813 to T-0822. The plugin `sdlc-lite` is now `sdlc` 1.0.0 in marketplace `nonoun`, with three session modes: `sdlc:factory` (the former conductor), `sdlc:hybrid` and `sdlc:live`. `context`, `design` and `dev-tools` keep their versions and move to the `nonoun` marketplace. Changes and the full upgrade steps are in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrade notes

1. This is a clean break: every repository using `sdlc-lite` stops working until it is migrated. Follow the CHANGELOG `[1.0.0]` Upgrade list: reinstall as `sdlc@nonoun`, set `"agent": "sdlc:factory"` (or `sdlc:hybrid`, `sdlc:live`), re-resolve helper script paths to `~/.claude/plugins/cache/nonoun/sdlc/<version>`, and run `onboard.py setup --force` once for the new managed-block markers.
2. Pick a mode per repository with `onboard.py setup --init --mode factory|hybrid|live`, or by editing `"agent"`; the mode takes effect in a new session.
3. New repositories keep tickets in `.sdlc/tickets/`; existing ones are untouched.
