## Upgrade notes

- `run.sh` exits 5 for a planner, builder or plan-reviewer run on a ticket whose lane is solo; set `SDLC_LANE_OVERRIDE="<reason>"` to proceed (recorded in `skips.md`).
- `steps.py review` now asks for a plan review only when a step is at L4 or L5; a planner L3 plan, a replan, a merge step or a `## Plan review` line no longer forces `review L1`. `lane` for a size M ticket with more than 20 criteria prints `full`.
- `solo_run.py` exits 2 with `another solo run is live (pid N)` when a second run starts in the same task dir.
- `fanout.py` gates run through `gate_lock.py` by default; the slot cap comes from `--slots` or `SDLC_GATE_SLOTS` (default 2), and each gated command gets `SDLC_GATE_WORKERS` (cpus divided by slots).
- A `.limit` marker can now carry a `reset` field.
- Docs under `docs/lean-sdlc/` moved to `docs/sdlc-lite/`.
