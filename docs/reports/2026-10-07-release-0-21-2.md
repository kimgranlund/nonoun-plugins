## Upgrade notes

1. Update the plugin before migrating any ticket sizes. A cached 0.21.x plugin does not read `size: L1` or `size: L2`; its `steps.py lane` prints `full` for them (observed by the T-0342 verifier, finding 2), so migrated L1 and L2 tickets would run the full chain. The new plugin reads old sizes, so nothing needs migrating on upgrade; run `tickets.py migrate-size --apply` afterwards if you want the levels written.
2. A repository that already ran `onboard` sees its managed `.sdlc` block reported stale (`onboard.py check` prints `stale AGENTS.md`; the T-0342 verifier reproduced it, finding R3) until `onboard.py setup` refreshes it. This record does not claim `setup` was run in any consumer repository.
3. Fanout output says `level L1` where it said `tier S`. No parser of the old text was found in this repository; a consumer script that parses it needs the new word.
4. The old `solo-S`, `solo-M`, `solo-L` and size S, M, L, XL names are deprecated aliases for one release. `sdlc-lite:solo-S` is no longer a shipped agent definition, so only the spawn hook still accepts the name; launch solos by the new names.
5. Run records written by `dispatch.py record --transcript` now carry a `resolved_model` field; `model` still holds the alias.
6. Sub-agent lane commits no longer stage a `*.log`, `.run.lock` or `*.running` file even when a ticket creates one on purpose (as 0.21.1 did for headless lane commits).
