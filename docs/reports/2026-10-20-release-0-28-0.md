# Release 0.28.0 (2026-10-20)

This release addresses all 23 open GitHub issues (#9 to #31), filed from a context-routing audit of one ui-kit-neue conductor session on 0.27.0. They became 27 tickets (T-0645 to T-0671), plus three found while building them (T-0672 to T-0674). Most of the audit's measured cost was conductor bookkeeping and inline role results; the rest was guidance that never reached the roles. Changes are listed in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrade notes

1. Install 0.28.0. Conductors call `dispatch.py advance` once per role completion, and `record --agent-id <id>` with nothing on stdin; the role's result is the file its brief names.
2. Roles now write their result to `Report file:` and end with one pointer line. A conductor reads the file only when the status needs action.
3. A lane dispatch refuses (exit 5) when its handoff names a guidance path that main or the integration branch holds but the lane lacks; run `fanout.py sync <lane> --paths .agents/,AGENTS.md,.claude/` and prepare again.
4. Plan lint is stricter: a step that edits a routed path must list its skill under `### Read first`, a quantified prose criterion needs a command, and `git stash` or `--autostash` in Do text is refused.
5. The four `plan-*` redirect stubs are gone; use `/sdlc-lite:plan <kind>`.
6. Run `onboard.py setup` to refresh the managed AGENTS.md wording and the `designs/` home.
