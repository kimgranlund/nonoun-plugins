# Release 0.31.0 (2026-10-22)

An agent-ui planner (T-0393, 0.30.0) could not save a draft in the scratch dir its brief named: the role write hook allowed only the result path. Fixing it, and following the verifiers' findings, became 7 tickets (T-0706 to T-0712). Changes are listed in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrade notes

1. Install 0.31.0, then `/reload-plugins`.
2. A `dispatch.py prepare` sub-agent that writes `"$SDLC_TMP_WORKTREES/..."` is now refused: the variable is unset there and the shell would run the command at `/`. Use the literal prefix from the brief. Roles launched by `run.sh` still have the variable set and keep working.
3. Read-only roles may write scratch files under the scratch root; nothing else changes for them.
