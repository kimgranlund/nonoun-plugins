# Release 0.25.0 (2026-10-19)

Tracked work records can now live in `docs/work/` instead of `.sdlc/`, opt-in per repository, plus docs naming, index and cap rules and three fixes. This repository is the first to migrate. Changes are listed in [CHANGELOG.md](../../CHANGELOG.md); the design is [T-0618](../work/.0618-work-records-in-docs/handoff.md).

## Upgrade notes

1. Install 0.25.0 on every host that works in the repo. Nothing changes for a repository until it opts in.
2. To migrate a repository, from its root with a clean tree and no running role: `python3 <plugin>/scripts/tickets.py --root .sdlc migrate-work-root --to docs/work --dry-run`, then the same without `--dry-run`, adding `--rewrite-refs` to rewrite live path mentions. Review `git diff` of every file outside `docs/work/` and `.sdlc/`: revert rewrites in plugin scripts, history prose and links pinned to old commits. Then commit, and run `tickets.py --root .sdlc check`.
3. A `ticket_root: tickets` or `layout: topics` repository is flattened into `docs/work/` by the same command.
4. New `docs_check` findings (D-12 numbering for new files, D-13, D-14) are warnings until `docs/layout.md` raises them under `## Levels`.
