# Release 0.24.0 (2026-10-15)

A minor release: worktrees move out of the repo to a sibling folder on both hosts, lanes finish in one command, and a repo can pin the plugin version every host must run. Changes are listed in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrade notes

1. Install 0.24.0 on every host that works in the repo (Claude Code and Codex install separately).
2. From the main checkout: `bash <plugin>/scripts/migrate-worktrees.sh` (dry run), read every `would` and `skip` line, then `--apply`. Rerun after a skipped lane lands. Lanes left under `.claude/worktrees/` or `.worktrees/` still land during this release.
3. Optional: add `plugin_min: 0.24.0` to `.sdlc/config` so no host runs an older plugin in the repo.
4. Rerun `onboard.py setup` to refresh the root `AGENTS.md` block (worktree root and the Codex full-access rule).
5. Under Codex, run lane steps with full access; the `workspace-write` sandbox cannot write `.git` or the sibling lane tree.
