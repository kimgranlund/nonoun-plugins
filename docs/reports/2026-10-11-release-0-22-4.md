## Upgrade notes

1. Adopt 0.22.4 and run `/reload-plugins`.
2. To hand a plan to a smaller session: write it with `/sdlc-lite:plan-doc`, approve it by setting `status: approved`, `approved_by:` and `approved_on:`, and start the driver with `SDLC_ROLE=conductor` and `SDLC_HEADLESS=1` exported, as `/goal complete build and verify <plan-doc.md>`. Start it from the repository that holds the plan doc.
3. A stopped plan resumes with `plan_done.py resume <plan-doc>` after its cause is fixed; do not delete `plan-state.json`.
4. A driver runs `dispatch.py recover --root . --open`. The bare `--root .` form still rewrites the attempt files of closed tickets.
5. After `fanout.py land`, bring the close back with `fanout.py settle <integration branch>` in the starting checkout. It is local only.
6. Nothing from 0.22.3 changes: the mailbox, close-first wording, held criteria and `~/.claude/lane/sweep.py` notes of that record still apply.
7. A Codex repository that installed the generated agents regenerates them (`codex_roles.py install`) to pick up the new fingerprint.
