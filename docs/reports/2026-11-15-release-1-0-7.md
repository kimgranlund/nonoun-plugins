# Release 1.0.7 (2026-11-15)

Marketplace release for 9 tickets, T-0846 to T-0854: `context` 0.8.0, `design` 0.4.0 and `dev-tools` 0.1.1 and `sdlc` 1.0.3. Changes are listed in [CHANGELOG.md](../../CHANGELOG.md), [the context changelog](../../plugins/context/CHANGELOG.md) and [the design changelog](../../plugins/design/CHANGELOG.md).

## Upgrade notes

1. Update `sdlc@nonoun`, `context@nonoun`, `design@nonoun` and `dev-tools@nonoun`, then `/reload-plugins` or start a new session.
2. `context` no longer ships `progressive-context`, `knowledge-modeling`, `context-routing-review`, `knowledge-organization-system` or `controlled-natural-language`. Use `context-system`; its validators are `scripts/validate_kos.py` and `scripts/lint_cnl.py`, and its templates are JSON (`vocabulary.json`, `rules.json`).
3. `design:hct-palettes` is now `design:ui-colors`. The generator id inside its output stays `hct-palettes@4`.
4. `ui-geometry` renames the built-in preset `massimo` to `standard`, with the same values.
5. `design` adds `ui-materials`, `ui-content`, `ui-interaction-dev`, `ui-frameworks`, `ui-explore-variants` and `ui-showcase-bento`.
