# Release 0.22.0

Recorded: 2026-10-08. SDLC Lite 0.22.0, a minor release to 0.21.3 (tag `v0.21.3`, commit f6a202d4). It is a minor release because it has one breaking change: the Claude headless execution path is retired. Progressive Context is unchanged: `git diff v0.21.3 main -- plugins/progressive-context` is empty, so its version is not bumped. Built from the branch `release-0.22.0`, cut from local main e1fa6e04, which is 101 commits past `v0.21.3` (`git rev-list --count v0.21.3..e1fa6e04`; main may have moved since the cut). The release commits add the version bump in the two SDLC Lite `plugin.json` files, this record and its docs index entry. The release is not tagged, pushed or published by these commits. The marketplace files carry no version field and are unchanged.

This record states only what a committed file or a command run for it shows. Where a record does not say something, it says so.

| Surface | Behavior now |
|---|---|

## Upgrade notes

1. A custom script that launched Claude roles through `run.sh` or `solo_run.py --exec` must switch to sub-agent dispatch (`dispatch.py prepare`, an Agent spawn, `dispatch.py record`; `fanout.py prep` and `land` for lanes) or set `SDLC_CLAUDE_EXEC=1`. The flag is the legacy path for bench and CI. A `fanout.py` caller that relied on the default `claude -p` driver must pass `--driver CMD` or use `prep` and `land`.
2. Spawn names changed to `<ticket>-<role>-L<n>[-<k>]`. A script or hook allowlist that matched the old `<role>-L<n>-<slug>` form must follow.
3. Solo L2 effort is now `high`. A repo that pinned the old `xhigh` expectation sees `high`.
4. A conductor on a verifier handoff now gets the pre-build commit as `Base sha`; a lane's base is its merge-base at dispatch.
5. Never run `onboard setup` or `tickets.py migrate-size --apply` in a consumer repository without the maintainer (unchanged from 0.21.3).
