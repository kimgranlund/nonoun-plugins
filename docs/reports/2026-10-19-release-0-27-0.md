# Release 0.27.0 (2026-10-19)

Conductors stop waking on a timer to report unchanged boards, `tickets.py inventory` shows which ticket branches have really landed, and `--rewrite-refs` no longer edits frozen records. Changes are listed in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrade notes

1. Install 0.27.0. A `/loop` with a fixed interval that reads as a status loop now fails `plan_check.py loop`; replace it with the driver turn in `run-plan`, which the role completion notification wakes.
2. A repo with a `## Frozen paths` list in `docs/layout.md` sees `kept frozen:` lines from `--rewrite-refs`; citations in those files keep their old paths by design.
3. To count idle wakes in a conductor session, pass its transcript with `traces.py ingest --conductor-transcript <jsonl>`.
