# Release 1.0.6 (2026-11-12)

Marketplace release for 10 tickets, T-0836 to T-0845: `context` 0.7.0 and `design` 0.3.0. `sdlc` 1.0.2 and `dev-tools` 0.1.0 are unchanged. Changes are listed in [CHANGELOG.md](../../CHANGELOG.md), [the context changelog](../../plugins/context/CHANGELOG.md) and [the design changelog](../../plugins/design/CHANGELOG.md).

## Upgrade notes

1. Update `context@nonoun` and `design@nonoun`, then `/reload-plugins` or start a new session.
2. `design` no longer ships `base-ui` or `mathematical-design-system`. Use `ui-geometry` for geometry; `component-variants`, `wireframe-review` and the `ui-kit-inspector` example carry their own trimmed kits.
3. Geometry values from the ported skills now come from `ui-geometry` and differ from the Differential Forms values, for example a 2px focus ring instead of 3px.
4. `evaluation-system` gates now require `pinned_target_version`, `classify-and-resolve` log records now require `level`, and every cascade `model` step needs a `question_set`. Older files fail validation.
