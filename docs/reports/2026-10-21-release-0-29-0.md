# Release 0.29.0 (2026-10-21)

This release addresses GitHub issues #32 to #43 and the reopened #10, #11 and #22, filed after ui-kit measured 0.27 against 0.28. They became 20 tickets (T-0676 to T-0695), plus T-0696, found by the T-0684 verifier. The measurement showed 0.28's routing, solo-report and advance changes not reaching ui-kit's sessions; T-0676, T-0677, T-0682 and T-0688 close those gaps. Changes are listed in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrade notes

1. Install 0.29.0, then `/reload-plugins`. A script that finds a newer version in the plugin cache prints one stderr line; re-resolve the scripts path when you see it.
2. Solo briefs now name a `Report file:`; the solo writes its result there and ends with one pointer line, as the other roles have since 0.28.0.
3. Run `steps.py routes` to see the skill routes the plan lint and briefs will use; `onboard.py check` warns when an AGENTS.md names repo skills but none resolve.
4. Merge main into an integration branch only with `fanout.py settle <integration> --catch-up`, never a hand `git merge`.
5. A `deferred: conductor` hold is settled with `dispatch.py settle-held`, not a second verifier run.
6. Optional `.sdlc/config` keys: `merge_union:` with `merge_union_gate:`, and several `lane_setup:` lines.
