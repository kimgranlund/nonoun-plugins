# Release 0.23.1 (2026-10-15)

A patch release on 0.23.0: fixes found while the fleet installed 0.23.0 and while this repo ran waves 76 and 77.

## What changed

| Ticket | Change |
|---|---|
| T-0561 | Bare clones get one worktree root outside every lane (`<bare parent>/lanes`, or `worktree_root:`), used by wtroot, lanes, fanout, the tmp reaper and both role hooks; `migrate-0.23.sh` reports "nothing to move" there |
| T-0562 | `block-background.sh` denies background Bash and Monitor for role sub-agents |
| T-0559 | Fanout closes write the real base and commits into the Outcome |
| T-0560 | Close moves `skips.md` to the records dir |
| T-0558 | `dispatch.py selftest` runs with a private `TMPDIR` |
| CI | checkout and setup-node v7, runner pinned to `ubuntu-24.04` |

## Upgrade notes

- Install 0.23.1. Nothing to migrate beyond 0.23.0's `migrate-0.23.sh`.
- A bare-clone repo that set `lanes_root: ../lanes` can drop the line; the default now resolves to `<bare parent>/lanes`.
- A role sub-agent that tries `run_in_background` or Monitor is refused with a message to rerun in the foreground.
