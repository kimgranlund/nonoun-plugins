## Upgrade notes

1. Install 0.34.0, then `/reload-plugins`.
2. `steps.py split` exits 2 with `environment error:` when a guard fails only because declared dependencies are not installed; install them and rerun, do not replan.
3. A merge that finds a lane's open copy of a closed ticket holding new content now stops as a merge conflict naming the files.
4. `lanes.py open --into <integration>` waits for `merge.lock`.
