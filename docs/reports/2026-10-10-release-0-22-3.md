## Upgrade notes

1. Adopt 0.22.3 and run `/reload-plugins`.
2. The close-first wording changes how roles behave. A verifier pass is final and is not re-verified unless a verified file changed. One verifier per ticket. A docs-only ticket skips the verifier (T-0429). The conductor stops and asks the maintainer after 6 agent runs on one step.
3. Keep the 0.22.2 mailbox behavior: `messages.py watch` and the version-free launcher `messages-run.py` from 0.22.2 are unchanged here.
4. Run `python3 ~/.claude/lane/sweep.py` to clear finished lanes. It is the maintainer's tool, outside this repository; run the dry run first and read the list before any removal.
5. A managed-block refresh in a consumer repository is allowed only under the T-0419 rule in `skills/onboard/SKILL.md`. Everything else, including `onboard setup` over the root `AGENTS.md` and `tickets.py migrate-size --apply`, still goes to the maintainer.
6. A plan criterion that reads its own step's verifier result is now a lint refusal (`plan defect`). Move such a criterion to the integration stage with `[owner: integration]`.
7. A Codex repository that installed the generated agents regenerates them (`codex_roles.py install`) to pick up the new fingerprint.
