# Release 0.30.0 (2026-10-22)

This release addresses GitHub issue #44: on 2026-10-21 six lanes, Codex and a second conductor drove an 18-core Mac to a load of about 128, all from test runners. It became 7 tickets (T-0697 to T-0703), plus two follow-ups found while building them (T-0704, T-0705). Changes are listed in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrade notes

1. Install 0.30.0, then `/reload-plugins`. Role hooks (disk scan, role write, role spawn and the rest) now fire for named teammates; on 0.29.0 and earlier they skipped every named sub-agent.
2. Gates now wait while the load is over `0.8 x` the CPU count and another gate holds the lock. Set `gate_lock.py policy set max_load=N` to change it, or `max_load=0` to turn it off.
3. `fanout.py prep` opens 1 lane when the load is over the cap; pass `--force` for all.
4. Add a worker cap to gates that run `node --test`, `vitest`, `playwright` or `jest`; prep warns until you do.
5. Readers of `report-written-unrecorded` must read `report-unrecorded`.
