## Upgrade notes

1. Install 0.26.0. The next `tickets.py roadmap` (also run by `new`, `claim`, `release` and `close`) writes `.sdlc/by-hand.md` and the router link; commit both.
2. Run `onboard.py setup` to refresh the "Adding a document" steps in `docs/AGENTS.md`.
3. Work done by hand leaves `ROADMAP.md` and the router stale until the next plugin run; `tickets.py check` warns on each `closed by hand (unverified)` ticket so it can be verified later.
