## Upgrade notes

None required for a conductor or a consumer's own project. Three things to know. First, headless fanout lane commits no longer stage a `*.log`, `.run.lock` or `*.running` file even when a ticket creates one on purpose, so a project whose tickets commit log fixtures must add them another way. Second, the scout `haiku` alias can resolve to another model on some logins (see Known limitations). Third, `scripts/cost_estimate.py selftest`, which `scripts/check.sh` runs, now reads `docs/reports/2026-10-06-l3-verifier-row-outlier.md`, so it fails on a copy of the plugin without the repository's `docs/` folder. A conductor that already passes `--transcript` to `dispatch.py record` sees no difference. A consumer that pinned the printed scout model `claude-haiku-4-5` now sees `haiku` in the dispatch JSON and record; the headless `run.sh` fallback still passes the pinned id, so `runs.jsonl` can hold both values; no levels, prices or agent table value changed (`prices.json` differs only in a note's report path).

## Verification

T-0333 ran an independent L3 verifier (fable, a different model family than the solo sonnet builders, T-0332 having no builder record; transcript model fields read `claude-fable-5-1`) over the 12 sub-agent tickets that closed in 0.21.0 without a verifier verdict, through `dispatch.py prepare`, a spawn of `sdlc-lite:verifier-L3`, and `dispatch.py record --transcript`, in six batches. Verdicts are in `.sdlc/verify-subagent/` (`summary.md` and one file per ticket): 9 pass (T-0275, T-0279, T-0284, T-0286, T-0326, T-0327, T-0329, T-0330, T-0332) and 3 fail (T-0280, T-0328, T-0331). The three fails map exactly to three tickets of this release (T-0334, T-0335, T-0336; T-0337, T-0339 and T-0340 did not come from T-0333):

- T-0280 (label drift and stale docstring): resolved by T-0335, which fixed the docstring and kept the code's label `usage fields x rates` as the agreed one, so the criterion's literal `transcript usage x price` is not what the code writes.
- T-0331 criterion T0331-1 (launcher skills without `--transcript`): fixed by T-0334.
- T-0328 (T0328-1) and T-0331 (T0331-3), the L3 verifier row outside the 35 percent band: handled by T-0336 as an accepted outlier, not by a fix.

The L3 row stays outside the band. The T-0336 report states why: a refit that lifts it to 0.65 would push the L2 row (0.93 to 1.09) and the G and F rows above the band, because the fitted factors (input x225, output x1.27) already sit at the limit the other rows allow. The band holds for the L2 opus verifier row and the G, F and R1 fable rows (0.745, 0.830, 0.847). The cause of the L3 miss is not established; the guess that its cache read and write counts differ in kind is untested and its surviving transcript cannot confirm it.

The closed folders of T-0334, T-0335, T-0336, T-0337, T-0339 and T-0340 (`.sdlc/.NNNN-*`) each hold a handoff and a solo run line in `runs.jsonl`; none holds a verifier verdict.
