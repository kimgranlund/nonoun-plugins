## Upgrade notes

1. A repository with a mailbox gets the version-free entry point the next time `messages.py send` runs there, because every `send` rewrites the mailbox entry files and the launcher `messages-run.py`. A Monitor loop that restarts the same launcher command then survives a plugin update. Run the watcher as `python3 "<mailbox>/messages-run.py" watch --receiver <name> --worker <worker>` (activated with `--kind watcher --window 1800`); `messages.py renew` is the manual form.
2. `dispatch.py record` for a sub-agent run now prints `unpriced:` when it cannot price the run. Pass `--transcript <jsonl>` to price it. The record still succeeds, and the row carries `unpriced: true`.
3. `steps.py widen` now rewrites a deny-path guard. The refusal for a form it cannot rewrite is unchanged, and `--reason` remains the fallback.
4. `dispatch.py prepare` now refuses an unfilled ticket template with exit 2. Fill the handoff before dispatching.
5. The placeholder regex in `steps.py` is narrower: an angle-bracketed word such as `<sha>` or `<step dir>` still counts, and a span such as `i<t ... >=` no longer does. A criterion that was silently dropped before is now kept and run.
6. A Codex repository that installed the generated agents regenerates them (`codex_roles.py install`) to pick up the new fingerprint.
7. Never run `onboard setup` or `tickets.py migrate-size --apply` in a consumer repository without the maintainer (unchanged from 0.22.1).
