# Release 1.0.11 (2026-11-24)

Marketplace release for T-0882 and PR #104: `design` 0.7.0. `sdlc` 1.1.0, `context` 0.8.0 and `dev-tools` 0.1.1 are unchanged. Changes are listed in [CHANGELOG.md](../../CHANGELOG.md) and [the design changelog](../../plugins/design/CHANGELOG.md).

`design` takes a minor version because the `ui-geometry` default preset changes from `ladder` to `affine`.

## Upgrade notes

1. Update `design@nonoun`, then `/reload-plugins` or start a new session.
2. `node scripts/derive.mjs` with no `--preset` now answers in the exact `affine` system, in px. Scripts that relied on the `ladder` default must pass `--preset ladder`. The plugin's own callers (`ui-frameworks` `tokens.mjs`, `component-variants` `geometry.mjs`) already do.
3. The eleven designer agents load on Claude Code only, as `design:<name>`. Codex does not load plugin agents.
4. The MacBook copy of `ui-geometry` predates #104. Sync it from the plugin before the next import, or the import would overwrite the change.
