## Breaking or notable for consumers

1. Scout and the messenger now run on Haiku 5.5 (`claude-haiku-5-5`). A Claude Code version that does not know the id cannot start them. In the live proof (Claude Code 2.1.293) the alias `haiku` resolved to `claude-haiku-5-5`; another login may resolve differently, which the level rubric states.
2. Update the plugin before migrating ticket sizes. Only the 0.21.2 and newer plugin reads `size: L1` and `size: L2` (see the 0.21.2 record, upgrade note 1).
3. Solo and verifier routing changed. After a solo, the default verifier is L2; L3 only by the rule above. A conductor or script that assumed a fixed L3 solo verifier, including fanout's old default, sees L2 now. A ticket that must get the Fable verifier needs a size of L4 or L5, a `verifier: L3` line, or an exact-label criterion.
4. A solo that reports `already fixed:` is closed without a verifier by the `/agent` skill; do not expect a verifier row for it.
5. A custom headless conductor can pass the routing reason with `--routing-reason`; the env var is still read when the flag is absent, but the env-prefix form does not match a headless `Bash(python3:*)` allowlist.
6. Never run `onboard setup` or `tickets.py migrate-size --apply` in a consumer repository without the maintainer.
