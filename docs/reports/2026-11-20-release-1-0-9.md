# Release 1.0.9 (2026-11-20)

Marketplace release for 25 tickets, T-0857 to T-0881: `sdlc` 1.1.0 and `design` 0.5.1. `context` 0.8.0 and `dev-tools` 0.1.1 are unchanged. Changes are listed in [CHANGELOG.md](../../CHANGELOG.md) and [the design changelog](../../plugins/design/CHANGELOG.md).

`sdlc` takes a minor version: the release adds commands, changes two defaults and adds one refusal. 17 of the tickets come from GitHub issues #85 to #102; #89 needed no change, since `gate_lock.py` already exits 3 on a slot timeout.

## Upgrade notes

1. Update `sdlc@nonoun` and `design@nonoun`, then start a new session. `/reload-plugins` is not enough for `sdlc`: a session still running from the older install folder is refused by `lanes.py`, `tickets.py`, `steps.py` and `messages.py` with exit 2 (T-0877). `SDLC_ALLOW_STALE_PLUGIN=1` runs with a warning.
2. Codex: rerun `codex_roles.py install <project>`; the generated agents carry the new profile revision.
3. A new repository with no `.sdlc/config` now gets `work_root: docs/tickets` from `onboard.py setup --init` (T-0857). An existing `.sdlc/config` is never changed.
4. `gate_lock.py` capacity now follows the host, `max(6, min(CPUs // 2, RAM GB // 4))`, and keeps one default need of room (3 units) for jobs declared at 5 minutes or less with `run --expect <duration>` (T-0880, T-0881). A gate with no `--expect` counts as long: add `--expect` to short gates, or undeclared gates get one slot less than before.
5. Roles run the check a criterion names, or `check.sh --changed`, never the full `check.sh` (T-0859). The full suite belongs to the land gate and a release; after a fix to a red full run, `check.sh --rerun` reruns only the failed and affected jobs (T-0861).
6. `specgate.py check` flags a duplicate span only inside one step (T-0879); a plan that repeated a check across steps to satisfy the old rule still passes.

## Known limits

- T-0881: on a capacity 6 host, undeclared gates run one at a time instead of two.
- T-0877: after an update, the messages launcher's `read`, `ack` and `wait` exit 2 in a running session until it restarts. No ticket is filed.
- T-0857: a repository that has `docs/layout.md` but no `.sdlc/config` gets the new `work_root` line, and `docs_check` may flag the layout. New ticket folders are plain `<slug>/`.
- T-0872: the conflict-marker guard covers `lanes.py finish --no-ticket` only.
- T-0865: `gate_lock.py status` shows stale jobs and does not cancel them.
- `lanes.py finish` leaves an untracked `skips.md` in the open ticket folder path after a landing.
