# Release 0.24.1 (2026-10-15)

Fixes found as the fleet installed 0.24.0, chiefly onboarding setup, plus claim and id refs and lane locks. Changes are listed in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrade notes

1. Install 0.24.1 on every host that works in the repo.
2. `onboard.py setup` is now refresh-only: it updates a managed block the repo already has and writes nothing else. It prints what `--init` would add; run `--init` only when you want those files. This replaces the 0.24.0 note that told every repo to rerun setup.
3. Topic-layout repos: run `tickets.py --root .sdlc roadmap` once; `check` reports the router block stale until then.
4. Tickets claimed before this release have no claim ref; `check` warns until `tickets.py claim <id> --by <agent> --handover --reason "<why>"` adds one, or the ticket closes.
5. Lanes opened with `lanes.py open` are now locked until close or `lanes.py finish`; a lane that ends any other way needs `git worktree unlock <path>`.
