# Release 0.36.0 (2026-10-25)

38 tickets in five waves: the owner-tree root cause (T-0734, split into T-0749 to T-0752), the run.sh-era audit (T-0735), three live sub-agent rehearsals' findings, and GitHub issues #73 to #82. Changes are listed in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrade notes

1. Install 0.36.0, then `/reload-plugins`.
2. Sub-agent lanes: `fanout.py prep` refuses a base that is not on the remote default branch, because Claude Code cuts each sub-agent worktree from it. After a `settle` that moved main, the next sub-agent round needs main pushed; that push is the user's call (the fanout skill says to ask).
3. Run `dispatch.py record --agent-id <id>` (or `advance --agent-id`) before `land` for each host lane: it rebinds the host record, and land resolves the printed branch name only through it.
4. A plan criterion that reads `$SDLC_BASE_SHA` needs a top-level guard (`: "${SDLC_BASE_SHA:?}" &&` or an export prefix); `steps.py lint` refuses it otherwise.
5. Remove landed `.claude/worktrees/agent-*` trees and branches with the lines settle prints; the plugin never removes or pushes them.
