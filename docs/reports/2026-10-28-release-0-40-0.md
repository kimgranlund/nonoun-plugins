Changes are listed in [CHANGELOG.md](../../CHANGELOG.md); the measurement is [the speed experiment](2026-10-28-speed-experiment.md).

## Upgrade notes

1. Install 0.40.0, then `/reload-plugins`.
2. A repository that lands lanes into its own main while main tracks a remote should add `lane_landing: local` to `.sdlc/config`; `lanes.py open --claim` then commits the claim. Repositories that land through pull requests need no change.
3. `lanes.py finish --backup` no longer waits for the push. Check `<git common dir>/sdlc-backup.log` or the next `finish`, which reports a failed push and exits nonzero.
4. Verifier briefs for small solo tickets may carry `Scope: diff`. A verifier that answers `escalate: full` gets the full brief on the next prepare.
