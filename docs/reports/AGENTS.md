# reports

Dated evidence: runs, reviews, audits, benchmarks and release records. Immutable: never rewrite a report to match later work; add a new dated one. Name a new report `YYYY-MM-DD-slug.md` (a release record is `YYYY-MM-DD-release-X-Y-Z.md`, dots become hyphens, date leads), with small evidence files in a sibling folder of the same stem. Pick by name or date; there is no per-file list.
