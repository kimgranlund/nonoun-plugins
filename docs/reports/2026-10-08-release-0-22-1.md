## Upgrade notes

1. A repository that uses the docs layout and wants the goals and KPI homes runs `python3 plugins/sdlc-lite/scripts/onboard.py check` and refreshes any managed docs block it reports as stale through onboard's own code path (with the maintainer), and `docs_check.py` then applies G-1 to G-5 to files in `docs/goals/` and `docs/kpi/`. A repository with no such files is not affected by the new checks. Do not hand-edit a managed block.
2. A handoff in the main checkout run from a lane worktree can name its base with a line `base: <sha>`. A supplied `SDLC_BASE_SHA` that disagrees with the chosen base is refused with a reason.
3. A step handoff criterion or guard must not use `grep -P`; `steps.py lint` refuses it.
4. A Codex repository that installed the generated agents regenerates them (`codex_roles.py install`) to pick up the new fingerprint note.
5. Never run `onboard setup` or `tickets.py migrate-size --apply` in a consumer repository without the maintainer (unchanged from 0.22.0).
