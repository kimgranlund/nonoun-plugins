## Upgrade notes

1. Install 0.41.0, then `/reload-plugins` in every session. A session still holding an older install folder now stops at `dispatch.py`, `fanout.py` or `solo_run.py` with exit 2. Helper scripts that hard-code a versioned plugin path must re-resolve it, or set `SDLC_ALLOW_STALE_PLUGIN=1` to keep the old warning-only behavior.
2. Verifier briefs no longer carry `Scope: diff` by default. Add `verifier_scope: diff` to `.sdlc/config` to keep it.
3. `tickets.py claim` no longer refuses over another ticket's broken `depends:`; it prints a warning. Run `tickets.py check` to see them all.
