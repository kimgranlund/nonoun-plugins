## Goal
A builder or solo agent is told, in its dispatched prompt, which repo skills govern the files its step changes, and opens them before its first edit to a routed path.

## Intent
- Do: (1) `prepare` in `plugins/sdlc-lite/scripts/dispatch.py` appends `Repo skills for this step: <path>, ...` to the builder and solo prompt, resolved with `steps.routed_skills(<tree>, paths)` (from T-0647) against the step's file scope: `steps.scope_entries` of a step handoff, else the existing repo-relative paths in code spans of a ticket handoff's `## Intent` and `## Context`; nothing is appended when no skill matches. (2) `agents/builder.md` and `agents/solo.md` say: open every skill under `### Read first` and on the `Repo skills for this step:` line before your first edit to a routed path; regenerate the level variants. (3) A `dispatch.py selftest` case covers the appended line and its absence.
- Non-goals: parsing AGENTS.md routing (T-0647 owns `repo_skill_routes` and `routed_skills`); verifier, planner or ui-designer prompts; lane-tree guidance checks (T-0655).
- Done when: the criteria pass.
- If Do needs more steps than this level allows (L1-L2 3, L3 6, L4 10, L5 15), file two tickets.

## Context
Source: GitHub issue #11, ui-kit-neue audit 2026-10-20. This ticket is part b (prepare and role prompts); part a is T-0647, which defines the routing parser and the `### Read first` skill line this ticket consumes.
- Evidence: 0 Skill-tool calls across 93 builders and solos; only 9 of 109 builders opened recipe-authoring; builders 0034-s3, 0035-s3, 0037-s1, 0049-s1 never read it and drew review findings on rules it states.
- `prepare` is `plugins/sdlc-lite/scripts/dispatch.py:944`; the prompt is assembled from `plugins/sdlc-lite/scripts/dispatch.py:1115`, with role-specific lines appended after it (the verifier block at `:1125`). Resolve against the run tree (`toplevel` in that function), so a lane gets the lane's routing.
- `agents/builder.md:8` already says to read every file under `### Read first`; `agents/solo.md` has no such rule.
- Level variants (`builder-L1.md` to `builder-L5.md`, `solo-L1.md` to `solo-L3.md`) are generated by `claude_roles.py generate`; Codex agents by `codex_roles.py generate`.

## Constraints
A prompt for a repo with no routing lines is byte-identical to today. The run.sh dry-run parity the dispatch selftest checks still holds. No model or effort change.
