## Goal
A plan step can no longer tell a builder to stash, and builder and solo agents are told never to stash.

## Intent
- Do: (1) `lint_steps` in `plugins/sdlc-lite/scripts/steps.py` adds a finding `steps: <plan> step <n>: plan defect: ### Do runs git stash or --autostash: <line>` for a line of the step's `### Do` section (`section_of(block, 'Do')`) holding `git stash` or `--autostash`, with a `steps.py selftest` case for each and one clean Do. (2) `agents/builder.md` and `agents/solo.md` add the rule the verifier brief already carries: never use `git stash` or `--autostash`; the stash stack is shared across sessions. Regenerate the level variants.
- Non-goals: changing `forbidden_git` for criteria; the verifier brief; `lanes.py ready`.
- Done when: the criteria pass.
- If Do needs more steps than this level allows (L1-L2 3, L3 6, L4 10, L5 15), file two tickets.

Source: GitHub issue #26, ui-kit-neue audit 2026-10-20.
- Evidence: the ui-kit-neue T-0050 plan used `git merge --autostash`.
- Confirmed anchors: the verifier brief forbids stashing at `plugins/sdlc-lite/scripts/dispatch.py:1131`; the `lanes.py ready` stash check is the selftest assertion at `plugins/sdlc-lite/scripts/lanes.py:3076`, and `ready` snapshots without stash (`plugins/sdlc-lite/scripts/lanes.py:174`).
- The issue cites `steps.py:1416`; in this tree that is `uses_grep_perl`. The real lint is `lint_steps` (`plugins/sdlc-lite/scripts/steps.py:2065`). It already refuses `git stash` inside an acceptance criterion through `forbidden_git` (`:1459`, regex `FORBIDDEN_GIT_RE` `:1416`), but never reads `### Do` and never matches `--autostash`. `section_of` is at `:1734`.
- `agents/builder.md` and `agents/solo.md` have no stash rule (`grep -n stash` finds none). Level variants are generated by `claude_roles.py generate`; Codex agents by `codex_roles.py generate`.

A Do line that only mentions stash inside quotes as an example of what not to do may still be flagged; keep the rule simple. No model or effort change.
