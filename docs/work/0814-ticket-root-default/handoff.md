## Goal
A repository that starts using SDLC Lite keeps its ticket folders in `.sdlc/tickets/`, not directly in `.sdlc/`: the first write that sets up a new repo records `ticket_root: tickets` in `.sdlc/config`.

## Context
- The user asked (2026-10-29): "tickets should be managed in .sdlc/tickets/* not directly in .sdlc/*", and chose "new repos only": existing repos are left exactly as they are, with no migrate command.
- `ticket_root: tickets` already exists as an opt-in (`plugins/sdlc-lite/scripts/roots.py`); agent-ui and ui-kit-maison use it. With no line, tickets sit flat in `.sdlc/`.
- A repo is new when it has no ticket folders anywhere under its state and work roots (no `.sdlc/NNNN-*`, `.sdlc/tickets/`, or `work_root:` folder, and no `refs/sdlc/ids/*`).
- Writers to check: `tickets.py new` (first ticket), `onboard.py setup --init`, and anything else that creates `.sdlc/config`. Defaults docs: `plugins/sdlc-lite/skills/handoff-format/SKILL.md`, `plugins/sdlc-lite/skills/ticket/SKILL.md`, `.sdlc/AGENTS.md` router text generated by `tickets.py roadmap`, `docs/specs/ticket-stages/`.

## Do
1. When `tickets.py new` runs in a new repo whose `.sdlc/config` has no `ticket_root:`, `work_root:` or `layout:` line, it appends `ticket_root: tickets` to `.sdlc/config` (creating the file if needed), prints one `config: ticket_root: tickets (new repo)` line, and creates the ticket under `.sdlc/tickets/`.
2. `onboard.py setup --init` does the same for a new repo (dry-run shows it in the diff).
3. A repo that already has flat ticket folders, any of those config lines, or ticket id refs is never changed.
4. Update the skill and spec text that names the default ticket location.

## Acceptance criteria
- `python3 plugins/sdlc-lite/scripts/tickets.py selftest` exits 0 with new cases: a new repo's first `new` writes the config line and puts the ticket in `.sdlc/tickets/`; a repo with an existing flat ticket keeps writing flat and its config is unchanged; a repo with `work_root:` is unchanged. Each new case fails before the change.
- `python3 plugins/sdlc-lite/scripts/onboard.py selftest` exits 0 with a case for `--init` in a new repo.
- `python3 plugins/sdlc-lite/scripts/check.py` exits 0.

## Constraints
- Never move or rewrite an existing ticket folder or config line.
