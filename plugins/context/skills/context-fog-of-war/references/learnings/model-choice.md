# Model choice

Applies to: runtime harness.

Observed in a five-round study of one runtime harness that renders generative UI, not universal law. Format and the other files: [README](README.md).

28. Pick the cheapest model that passes, per agent, not one model for the harness.
    - Observed in the five-round study: the cheapest passing model differed by persona in every round.
    - Check: a per-agent pass table across model sizes from the latest round.
    - Applies to: runtime harness.
29. Expect the smallest model to skip the surface tool; back the turn with a check.
    - Observed in the five-round study: the smallest model skipped the render tool on about a quarter of its turns in one round.
    - Check: count turns with no surface per model; a check sends each back.
    - Applies to: runtime harness.
