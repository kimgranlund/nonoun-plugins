## Task goal
When the Figma plugin skips renaming a stale variable because its `_deprecated/` slot is already taken, it currently says nothing. It should report that skip to the user.

Interface the tests rely on (library mode):
- Each site that skips a rename records the skipped stale name(s) as an array named `skipped`: on `applyBundle`'s `colorReports[]` entries, `applyFloatPlans`'s `libraryReports[]` entries, and `applyFontPrimitivesModes`'s `libraryReport`, with a top-level `skipped` rollup on the `applyBundle` and `applyFloatPlans` results. Use `[]` when nothing was skipped.
- The apply completion notice names the count as `N stale skipped (rename target taken)`, next to the existing counts.
- The Type/Geometry part of the completion notice also names kept stale breakpoint modes as `N stale kept (published library)`, the way the color part already does.

## Step 1: Record and report skipped stale renames (gates green)
level: L2
### Do
Edit only `figma/plugin/code.js` and `test/figma/plugin.mjs`; `npm test` regenerates `figma/binder/figma-semantic-binder/code.js`, `src/ui/figma-plugin-assets.js`, and `figma/plugin/ui.html` (never hand-edit those; `scripts/gen-figma-binder-code.mjs` splices `applyFloatPlans` verbatim into the binder, so its parity gate follows the source).

1. `applyBundle` → `reconcileColorCollection` (about line 1616): split `if (!vr || byName[r.to]) continue;` into two cases: no live `vr` → continue as today; `byName[r.to]` already taken → push `r.from` onto a per-collection `skipped` array and continue (no rename, no `preserved++`, no `deprecates.push`, so `deprecates` keeps excluding skipped names as it does now). Add `skipped` to every `colorReports[]` entry (the classic, non-library branch gets `skipped: []`). Return a top-level `skipped` on the `applyBundle` result: the concatenation of every entry's `skipped`, `[]` when nothing was skipped (classic mode included).
2. `applyFloatPlans` (deprecates loop about line 1775): same split; `skipped` on each `libraryReports[]` entry (`[]` when none) and a top-level `skipped` rollup on the result (`[]` when none, including classic mode where `libraryReports` may be empty). Leave `deprecates` as it is (the reconcile plan).
3. `applyFontPrimitivesModes` (deprecates loop about line 1115): same split; `skipped` on `libraryReport` (`[]` when none), `deprecates` unchanged.
4. The apply handler (lines 169 to 208): the color part appends `, ${r.skipped.length} stale skipped (rename target taken)` after the existing pruned/kept fragments when the count is above 0. The Type/Geometry part appends, after `across N collection(s)`, `, ${floatStaleModes.length} stale kept (published library)` when that count is above 0 (`floatStaleModes` is already computed at line 180; move it to handler scope), then `, ${K} stale skipped (rename target taken)` when K is above 0, where K = `fr.skipped.length` plus the font-primitives `libraryReport.skipped.length`. Hoist the font-primitives result out of the styles `try` (`let fpr = null;` at handler scope, assigned inside) so the notice can read it; when there is no Type/Geometry part but the font-primitives apply skipped names, push a part of its own with the same `stale skipped (rename target taken)` wording. `console.warn` the skipped names per system next to the existing stale-mode warnings. Keep every existing notice fragment, its wording, and its order.
5. `test/figma/plugin.mjs`: add gate `staleskip` to `DECLARED` with `FAIL("staleskip", ...)` call sites (report-static needs both). Legs: (a) float: classic apply of Synth `a`, `b`, `_deprecated/b`, then library-mode apply of `a` only → the Synth `libraryReports` entry's `skipped` deep-equals `["b"]`, top-level `skipped` equals `["b"]`, and `b` stays live under its own name; (b) color: classic full `figmaBundle(defaultDocument())`, library-mode cut (`palettes.slice(0, -1)`), classic full again, library-mode cut again → every `colorReports[]` entry has a `skipped` array, their total equals the first library-mode apply's `preserved`, top-level `skipped` has that length, `preserved` and `pruned` are 0; (c) font primitives: same shape with a Type Primitives STRING plan of `font/a`, `font/b`, `_deprecated/font/b` → `libraryReport.skipped` equals `["font/b"]`; (d) empty case: a library-mode apply with no taken slot and a classic apply both yield `skipped: []` at every site; (e) handler: capture `figma.notify`, drive `figma.ui._h({ type: "apply", ... })`, and assert the color notice names `N stale skipped (rename target taken)` and the Type/Geometry notice names `1 stale kept (published library)` and `1 stale skipped (rename target taken)`. Update `floatlibrary`, `colorlibrary`, `librarymode`, and `fontprimslibrary` only where they assert on the exact report keys; never delete or weaken an assertion.
