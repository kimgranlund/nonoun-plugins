# Focus, adaptive routing and grouping remediation

Published source changes address the fresh evaluation and screenshot feedback; generated historical evidence is unchanged. These authored checks do not establish that future generated interfaces adopt the changes.

- Stepper routing explicitly defaults to adaptive marker/title/status/check anatomy. Minimal native numbering is an explicitly requested fallback.
- focusWorkflowStep resolves the destination heading after committed rendering; the prototype adapter transfers focus only for a changed stage and once per state object. Invalid fields keep their validation focus; initial mount and ordinary editing do not steal focus.
- The workflow guide distinguishes catalogue, derived summary and draft action groups, with bounded reading width or a purposeful desktop split. The collection recipe uses the explicit outer page gutter.
- wf-page owns a 4u outer gutter separately from wf-page-flow's 6u task gap. Routes and compact composition guidance name both owners; nested cards do not repeat page inset.
- Multiline wf-record-choice buttons use card-option geometry: 2u padding, 1u related-content gap and card radius. An explicit full-width grid track prevents inherited button centering from shrinking content. Table-cell and data-appearance=inline selectors use 1u padding and control radius. Metadata retains normal weight and no underline; selected paint remains visible after blur. The maintained Collections example includes title and metadata.
- Native select:open rotates the Phosphor indicator 180 degrees; focus alone does not imply open. No JS state guess was added. [MDN native select](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/select) documents this state.

Affected verification: 12 Chromium/Firefox/WebKit width/scheme contexts verify heading transfer, replacement h2 focus, editing focus retention, page/card/table inset ratios, card-title alignment and actual open caret rotation; a real zero-padding fault is rejected. The workflow lifecycle/isolation check passes, as do 12 adaptive/state contexts, 24 bounded pattern lookups and seven guard controls. Page rhythm passes 30 cases and three negative controls. Authored select geometry/inheritance/keyboard checks pass 12 contexts and stretched-slot controls. Staged sheets pass coverage/hash/navigation checks in 20 responsive cases. Composition extraction passes 35 anatomies and six rejection controls.

The original static-select check failed because it tried to reach a deferred iframe with scripts disabled. Its affected fixture binding now uses the exact maintained standalone native-select document; 60 page-control cases, no-JS fallback and three negative controls pass. Original errors are recorded separately in the publication notes; they are not interface failures. A preliminary new check read an unresolved custom property as a number; it now uses an independent rendered probe. Native-popup Escape automation is not used to claim installed Safari behavior.

Existing completed verification, historical reports, accepted limitations, generation pipeline and peer-owned live components.html are preserved. Updated demonstration source bindings authenticate dependencies, not observed behavior. Publication entry and package identities are recorded in the existing preview planning evidence. No fresh generation or holdout was run in this remediation.
