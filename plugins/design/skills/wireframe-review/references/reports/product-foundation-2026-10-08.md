# Product foundation hardening

Implemented after the eight-attempt generative evaluation and screenshot review. Historical artifacts were preserved.

## Delivered

- Explicit product typography, sidebar regions, wrapping navigation rows, fields/help, grouped fields, checkbox/radio choice rows/cards, notices and paired inverse surfaces.
- Text-only rows tolerate absent optional slots. Menu rows work independently of a special navigation wrapper. Phosphor regular names resolve through the existing direct CDN convention.
- Menu top-layer positioning escapes clipping ancestors within the iframe, clamps horizontally, flips vertically and bounds scroll height. Escape returns focus; outside activation closes. Unsupported top-layer engines retain a documented weaker fallback.
- Builder --controller extension; syntax checking before emission; safe script assembly; unresolved token references rejected before HTML output.
- Local controller lifecycle: unit/variant state isolation, session retention across rerenders, synchronized same-key views, listener cleanup, read-only overview/annotation views, plan-revision approval helpers.
- Final rendered gate checks startup/routes/overflow and refuses unverified implemented interaction claims. Task-specific browser checks remain necessary.
- Concise required component context and linked runtime contract; discovery registry updated. No speculative manifest expansion.

## Remaining limits

Browser coverage is Chromium; WebKit unavailable. Native popup behavior and all external glyph delivery remain platform/network checks. No universal contrast, visual or accessibility pass. Cross-leaf state is not implemented; coherent flows belong in one leaf or require an explicit future contract. Approval helpers do not validate domain policy. Raw literal overrides are still a review concern, not comprehensively rejected. A/B/C quality and omitted interaction promises require comparison with the brief.
