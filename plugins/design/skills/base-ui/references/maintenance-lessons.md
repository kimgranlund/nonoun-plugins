# Evidence-backed maintenance boundaries

Use the responsible maintained source; do not accumulate generic author instructions to compensate for missing mechanics.

- **Commands:** runtime `onAction` owns nearest-native-button dispatch. State/payload attributes on ancestor containers must not activate commands. Actions/collections records link the recipe and executable checks.
- **Dynamic IDs:** `findUIElementById` treats an ID as data and scopes lookup to a root. The restoration recipe owns optional focus/disclosure restoration; it does not define application navigation policy.
- **Colors:** `semantic-palettes.json` owns group/sample mapping. Independent Primes supply opt-in solid accents and their interaction states; Base supplies paired text and supporting surfaces. Exact source identity and contrast are separate checks. Neutral components omit data-intent; Material is an explicit palette intent. Source exports contain no semantic-role decisions.
- **Geometry:** the shared component contract's `containerSpacing` and the implemented CSS own profile defaults. Audit alignment, excessive gaps/margins and expanded states—not only missing padding or overflow. Base-ui's generated local margin unit follows density spacing d (equal to n only at Regular); see [integration boundary](../../../../Projects/ui-kit/docs/system/geometry-contract.md). Dedicated surfaces may have their own margins.
- **Native/specimen parity:** Sheet 42 exposed late native radio/choice CSS overrides after specimen geometry passed. When changing shared dimensions, check both native kit anatomy and custom recipes, then verify nominal frames separately from wrapped/enlarged content growth.
- **Promotion:** a generated app fix is evidence, not an automatic shared-system fix. Identify the reusable mechanism/contract, update its discovery route and affected executable checks, then verify a consumer. Keep app-specific business rules local unless reuse warrants a shared recipe.

Reports live in the Context Fog-of-War user library and registry, not only inside this skill. Preserve original failures and first runnable artifacts. Distinguish deterministic checks, fresh-author discovery, evaluator corrections and repaired success; a single attempt does not establish general reliability.

- **Spec parity:** Audit symbolic labels as well as numeric readouts after changing geometry. A correct computed Badge height can coexist with stale padding labels or duplicate Chip type rows. Keep historical sheet artifacts unchanged; publish reconciled specs as a new sheet.
- **Motion parity:** Changing shared timing also requires updating recipe prose, component contracts and checks that wait for or assert settled paint. Native Smooth perceptual duration differs from settling duration; preserve the sampling source and browser interruption limitation.

- **Slot integration:** Preserve fixed3n media/icon/glyph wrappers and separate artwork dimensions. Package and installed-kit sources have independent builds; use the [integration record](../../mathematical-design-system/references/ui-kit-integration.md). Inherited media shape needs an explicit measured parent-radius result when retention is active.
- **Focus guard specificity:** Modality guards should not outrank component inward outline geometry. Verify keyboard ring bounds after establishing keyboard modality; pointer-no-ring behavior is a separate assertion.
