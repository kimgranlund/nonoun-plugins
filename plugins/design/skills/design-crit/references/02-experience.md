# Stage 2 — Figma-inspired experience density and sequence review

## Own

How work unfolds: meaningful moments, grouping, progressive disclosure, continuity, and the user's information/decision burden. Evaluate both too much at once and unnecessary fragmentation. A sparse screen is not automatically an easier experience.

## Ask after the task model is settled

- At each moment, what must the user understand, decide, and remember?
- Which information must be seen together to compare or authorize confidently?
- Would a few dense moments or a sequential set of lighter moments better serve this user's expertise, frequency and stakes?
- Does splitting the task reduce uncertainty, or introduce memory burden, backtracking and extra commits?
- Can optional detail be deferred without hiding prerequisites, consequences or recovery?
- What context survives switching, returning, interruption, cancellation and background completion?

## Evaluate

| Criterion | Supported when |
| --- | --- |
| Decision load | Each moment has a legible purpose and a manageable set of competing choices for the intended user. |
| Information dependency | Evidence needed for a decision is available before the commitment; comparison content stays together. |
| Sequence economy | Steps correspond to meaningful task boundaries, not arbitrary screen minimalism. |
| Continuity | Drafts, selection, location and progress have explicit ownership across transitions. |

Sketch a compact moment map: entry → understanding/choice → commitment → result/recovery. Compare dense versus staged approaches only when there is a real tradeoff; recommend one with a reason. Do not use magic limits on controls, clicks or steps, and do not turn every form into a wizard.

Do not choose brand styling or rewrite the settled domain vocabulary. Route a newly discovered ownership contradiction back to stage 1. Hand off the chosen sequence, what stays visible, what is deferred, and what must persist.

## Exit

The interaction sequence is coherent without unresolved foundational choices. Later reviewers can select familiar patterns without having to invent the workflow.

For inside-out validation, identify the continuity dependencies between moments: which information, draft, selection or result must arrive intact at the next moment. Trace local transitions into the whole journey; inspect aggregate decision load, backtracking and duplicate commitments even when each screen is individually clear.
