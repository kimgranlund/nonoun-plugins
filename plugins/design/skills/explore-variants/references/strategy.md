# Recipe: a plan, or a choice among courses

Read before step 3 of the procedure when the question is which course to take: a strategy, a sequence, a build or
buy, a yes or no with consequences.

| | |
|---|---|
| Specimen | The plan on one screen: its first three moves in order, what each costs, what each makes possible next, and what is true at the end if it works. A pitch for the plan is not the plan. |
| Fixture | The same market, budget, people and dates for every variant, stated once at the top of the page. |
| Stress | Named scenarios as a button group marked `data-fb-control-group`: a competitor answers, money is late, a key person leaves, the main assumption is false. Each variant restates its moves and its outcome for each scenario. |

## Choosing variants

The usual axes: what is done first, what is given up for good, who carries the risk, how soon it can be undone,
whether it bets on one thing or several. "Do nothing" and "decide later" are variants when they are real courses.

## Rules for the specimens

- Where a variant rests on figures, the figures are a small model on the page with inputs the reader can change,
  the same inputs for every variant.
- Each variant carries Depends on, and every claim is marked measured, sourced, estimated or assumed. A page of
  assumptions says so in its reading.
- Each variant says what would be seen, and by when, if it is going wrong.
- Aspects are the things a decider weighs: "We can afford it", "We can undo it", "It gets us there in time",
  "I believe the assumption".
