## Goal
Small follow-ups get finished in the session that found them: /chain runs a Loose ends step, `/fix` is a fast lane for size-S asks, the filer tags each follow-up `fix-now:`, `decide:`, or `note:`, and `tickets.py close` files at most one ticket per task (only a `decide:` item named with `--ticket N`) and appends the rest to `.sdlc/notes.md`, enforced in code with a selftest.
