## PR title
T-0210: Spec gate A1: specgate.py check, run.sh plan-reviewer refusal, plan guard-timeout line

## PR body
### Summary
This adds the free half of the spec gate (A1 in `docs/lean-sdlc/cost-control.md`). It catches plan defects before a plan-reviewer model call:
- a `(guard)` that runs `check.sh` with no timeout line
- a criterion span repeated verbatim across steps
- a `(red)` tag beside `(guard)` on one line

A plan can now carry a `guard timeout: <seconds>` line, and `steps.py split --only` uses it. `run.sh plan-reviewer` refuses a failing plan with exit 2 before any run is recorded.

### Changes
- `scripts/specgate.py` (new): `check <plan | task dir>` and `selftest`. It imports `steps` and defines no second criterion parser. It is read-only and exits 0 or 1. Findings go to stderr. A target with no plan is skipped.
- `scripts/steps.py`: new `plan_guard_timeout` and `step_guard_timeout` helpers. For each step, `--guard-timeout` resolves in this order: the explicit flag, the step's own line, the plan's line, then 300. Three new `(guard timeout)` selftest cases.
- `scripts/run.sh`: for role plan-reviewer only, `specgate.py check "$dir"` runs before the `run_lifecycle.py` exec. On findings it exits 2 with no `runs.jsonl` line, no `.running` file and no attempt record. `SDLC_SPECGATE=off` skips the gate and writes `specgate: "off"` on the run line. It is skipped when `SDLC_LIFECYCLE_CHILD=1`.
- `scripts/run-selftest.sh` and `scripts/check.sh`: spec gate cases, and `specgate.py selftest` wired in.
- Guidance, one rule or pointer each:
  - `agents/planner.md`: rule 14 sub-bullet on timing a whole-suite guard once and writing the timeout line.
  - `skills/handoff-format/SKILL.md`: the `guard timeout:` line.
  - `skills/chain/SKILL.md`: an exit 2 with `specgate:` lines routes to a replan.
  - `agents/conductor.md`: a pointer clause to that routing.
- `scripts/check.py`: docstring item 16 and a spec gate guard. It checks that the key phrases are present and that `specgate.py check` comes before the exec in `run.sh`. Each check has a built-in negative control.
- `docs/references/sdlc-internals.md` and `docs/lean-sdlc/cost-control.md`: updated so they don't go stale.
- Codex agents regenerated by `codex_roles.py generate`: the conductor L1 and planner L1, L2, L3 TOML files.

No model or effort default changed. There is no version bump, tag, push or publish.

## Changelog entry
- Added the spec gate (A1). `scripts/specgate.py check` flags a whole-suite `(guard)` with no `guard timeout:` line, a criterion repeated across steps, and `(red)` beside `(guard)`. `run.sh plan-reviewer` refuses such a plan with exit 2 before any model call (`SDLC_SPECGATE=off` skips it). `steps.py split --only` now uses the plan's or step's `guard timeout:` line as its default.

## Follow-ups
- fix-now: `check.py` order check uses the first `specgate.py check` line in `run.sh`, which is the header comment at run.sh:63, not the command at line 265; point it at the command line so it can't pass on the comment.
- note: On macOS, where `timeout` is not on PATH, `steps.py` does not treat a span starting with the bare word `timeout` as a command, so `specgate.py` does not see it either. The `timeout N` prefix only counts inside a span that already counts as a command, for example `cd . && timeout 900 bash scripts/check.sh`.
- note: A plan with more than one `guard timeout:` line outside its step blocks uses the first positive value, and 0 or less is skipped.
