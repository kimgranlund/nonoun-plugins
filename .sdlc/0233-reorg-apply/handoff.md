## Goal
A script applies an approved reorganization plan with the refusals and final check from docs/repo-onboarding/reorganization.md, so moving documents is as safe and testable as the onboarding setup.

## Intent
- Do: build the apply step described in docs/repo-onboarding/reorganization-plan-procedure.md (Step 3) and the draft rules (Plan, Apply, Refusals, Final check, Validation required before shipping): digest check, dry run, citing-file scan with link rewriting, one Git commit per batch, baseline-compared final check, restore on failure, and every gate with a positive case and an observed negative control. Settle the open findings (N1 to N15) that this step needs, using what the inventory run on real repositories showed (docs/validation/reorg-inventory-live-run.md).
- Non-goals: an LLM making the moves (the plan is generated by a session, applying is deterministic); changing `.sdlc/` layouts; a version bump, tag, push, or publish.
- Done when: apply passes its validation table in a throwaway repository, refuses a plan whose digest changed, and an independent verifier passed with an overall pass. Size L: plan it, it touches links across a repository.

## Context
Follows the read-only inventory ticket. Not started: depends on it. The first design has been through three review rounds that each found new edge cases, so write the apply step against real plans from step 1 and settle rules from them, not on paper.

## Constraints
Philosophy: "Done is better than perfect." Never move a frozen file or anything under `.sdlc/`. No em dashes.
