## PR title
T-0233: Gated apply for an approved reorganization plan (reorg.py)

## PR body
### Summary
Adds `reorg.py`, a deterministic script that applies an approved reorganization plan. It enforces the refusals and the final check from `docs/repo-onboarding/reorganization.md`. The plan is still generated by a session; the script only applies it. It never moves a frozen file or anything under `.sdlc/`.

### Changes
- `plugins/sdlc-lite/scripts/reorg.py` (new): `apply PLAN [--root DIR] [--dry-run] [--approve DIGEST]` and `selftest`.
  - Gates: digest check, dry run, citing-file scan with link rewriting, one Git commit per batch, baseline-compared final check, restore on failure, and a managed-block hash refresh.
  - The dry run never runs the final check.
  - A link in a file that moves in the same batch is rewritten once.
  - A cross-batch citation is rewritten again in the later batch.
  - It imports `onboard`, `rename_refs` and `inventory` instead of copying their regexes.
- `plugins/sdlc-lite/scripts/check.sh`: runs `reorg.py selftest`.
- `plugins/sdlc-lite/scripts/check.py`: docstring item 38 and a `REORG_NEEDS` guard, with a negative control per phrase per file.
- `docs/reports/reorg-apply-live-run.md` and `docs/reports/reorg-apply-live-run/` (10 evidence files): the live run on a clone.
- `docs/repo-onboarding/reorganization.md`, `reorganization-plan-procedure.md`, `README.md` and `docs/README.md`:
  - The "not built" status text now describes the built `reorg.py`.
  - The validation table gains a Selftest gate column.
  - The open findings table gains an Outcome column. N1, N2, N3, N5, N8, N9 and N15 are marked Settled or Not applicable.
  - The `git log --follow` assumption now cites the live run.
