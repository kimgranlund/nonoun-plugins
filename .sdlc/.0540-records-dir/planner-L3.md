In `plugins/sdlc-lite/scripts/order.py` add:
- `records_dir(task_dir, create=False) -> pathlib.Path`. Paths are made absolute with `os.path.abspath` and never `realpath` (the criteria compare against the `mktemp` path). Base: the nearest ancestor named `.sdlc`, else the dir's parent. Key: the folder name with leading dots stripped (`.0002-b` gives `0002-b`). Rules, first match wins:
  1. A path already inside `<base>/runtime/tasks/` returns itself.
  2. A `step-<n>` dir (also `step-<n>.superseded-<k>`) returns `records_dir(parent)/<its name>`.
  3. `<base>/runtime/tasks/<key>` exists: return it.
  4. Legacy: the dir holds `runs.jsonl`, any `*.attempt.json`, `skips.md`, a role result (`order.LOOSE` match ending `.md`, e.g. `planner-L2.md`, `builder-L2-2.md`), or a `step-<n>` dir: return the dir itself.

  The legacy markers are wider than the design's (`runs.jsonl` or `*.attempt.json`) on purpose. Evidence: this file's own selftest fixtures at order.py:150-155 hold result files and no `runs.jsonl`. The hand-placed `skips.md` fixtures in dispatch.py:1821-1826 do the same, and so do the hand-written `step-1/` dirs the /fix skill writes until T-0543. - `task_dir(path) -> pathlib.Path | None`, the reverse map.
