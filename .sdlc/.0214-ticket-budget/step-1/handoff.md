1. New `plugins/sdlc-lite/scripts/budget.py` (stdlib only; `import tickets` from its own directory for the front matter parser, as `board.py` does) with subcommands `status`, `set`, `ack`, `selftest`.
   - `ticket_of(path)`: from a ticket dir, a step dir, a `step-<n>.superseded-<k>/step-<n>` dir, or a handoff.md, walk up to the nearest `handoff.md` whose front matter parses as a ticket (dict with an `id`). Stop at the filesystem root or at a dir named `.sdlc`; return None when none.
   - Spend: sum `cost_usd` over every `runs.jsonl` under the ticket folder, recursively, deduplicated by `attempt_id` (a record with no `attempt_id` counts every time). A null or missing `cost_usd` counts 0 and adds one to `unmetered_runs`. Header comment: Codex runs record no cost, so the meter covers Claude roles only.
   - `status <path>`: resolve with `ticket_of`, read optional front matter `budget_usd` (a number; anything else counts as no budget). Ceiling is the `usd` in `budget-ack.md` (front matter in the ticket folder, written by `ack`) when that file exists and its usd is greater than `budget_usd`, else `budget_usd`. Print lines `spend: <x.xx>`, `budget: <ceiling>`, `percent: <int>`, `state: ok|warn|over`, `unmetered_runs: N`. State is `warn` at 80 percent or more of the ceiling and `over` at 100 or more. Exit 0 ok, 3 warn or over, 2 no budget (print `no budget` to stderr). No ticket found exits 2 too.
   - `set <ticket dir|handoff.md> --tier S|M|L` or `--usd N`: write or replace one `budget_usd: <n>` line in the front matter, nothing else changed (tier maps S 5, M 30, L 60). Refuse (exit 2) when the file has no front matter.
   - `ack <ticket dir> --usd N --reason TEXT`: require N greater than the current ceiling (else exit 2 and say so), write `budget-ack.md` with front matter `usd`, `reason`, `ts` (UTC ISO) in the ticket folder. A second ack replaces the first.
   - `selftest` prints `ok: <label>` per case and the last line `budget selftest: PASS`. Labels exactly: `status: under 80 percent is ok`, `status: at 80 percent is warn with exit 3`, `status: over 100 percent is over with exit 3`, `status: a duplicated attempt_id counts once`, `status: a null cost is unmetered`, `status: a superseded dir run counts`, `status: no budget exits 2`, `ack: raising the ceiling clears warn`, `ack: a lower usd is refused`, `set: tier S writes budget_usd 5`.
2. `plugins/sdlc-lite/scripts/run.sh`, inside the `{ ... }` group, immediately before the `exec python3 "$plugin_root/scripts/run_lifecycle.py"` line, and only when `SDLC_LIFECYCLE_CHILD` is not 1 (dry runs included): run `python3 "$plugin_root/scripts/budget.py" status "$handoff"` capturing output; on exit code 3 print `run.sh: budget <percent>%: ask the user; budget.py ack` to stderr (percent from the `percent:` line) and `exit 4`. Any other exit (0, 2, a crash) continues silently, so a ticket with no budget launches unchanged and nothing is written. Because the gate sits before the exec, no attempt record, `.running` file or `runs.jsonl` line exists after a refusal. Update the `Exit codes:` header line to add `4 ticket budget at 80 percent or more with no ack`. Keep every new line inside the group.

The first seeds a ticket whose `runs.jsonl` puts it at 85 percent of `budget_usd: 10`, asserts exit 4, the stub never called, and no `runs.jsonl` line or `*.running` added by the refused run.
