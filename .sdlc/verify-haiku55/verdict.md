## Findings

None is a release blocker for T-0353. All are pre-existing or evidence-hygiene items.

- F1 (defect, pre-existing, not a blocker): `dispatch.py record` prefers a non-empty stdin over `--transcript`. Root cause: `record()` (scripts/dispatch.py around lines 642 to 649) takes stdin as the result whenever it holds a `## ` heading and is not a truncation of the transcript's final message; the transcript is a fallback only when stdin is empty or truncated. So a conductor's re-typed paste (the builder's run turned `&lt;name&gt;` into `<name>`) silently replaces the verbatim sub-agent message even when `--transcript` is passed. Suggested fix: when `--transcript` is given and its final assistant text is a complete result, prefer it and log a one-line notice when stdin differs. Ticketable.
- F2 (evidence hygiene): `docs/reports/2026-10-07-haiku-5-5/stream-trimmed.jsonl` holds two `system init` and two `result` entries with identical `modelUsage` and `total_cost_usd`; the second result carries the permission denial, the first does not. Looks like a trimming duplication, not two runs. The proof is unaffected (my fresh run reproduces it), but the committed proof is a derived model list, not the raw transcript, so it cannot be re-derived from the repo alone.
- F3 (doc precision, prices.json `_note`): the cache figures quote only the up-to-100K tier ($0.01 read, $0.125 and $0.20 write); the page also lists $0.05, $0.625 and $1 above 100K. Truthful but incomplete.
- F4 (headless usability, pre-existing): the conductor's documented prepare form `SDLC_ROUTING_REASON="<why>" python3 .../dispatch.py prepare ...` does not match a `Bash(python3:*)` allowlist, because the command starts with the variable assignment. My first headless attempt was denied twice on exactly that command and spawned nothing. The builder's proof did not hit this only because their conductor never set the variable: the committed dispatch record shows `"reason_source": "fallback"` and the generic routing reason. Exporting the variable before `claude -p` fixed it for my run. Worth one line in the conductor or headless docs (`env` form or a `Bash(SDLC_ROUTING_REASON=*)` allow).
- F5 (scope note): `.sdlc/evals/0000-baseline.md`, `.sdlc/AGENTS.md` and `.sdlc/roadmap.md` still say "Haiku 4.5" (historical eval and the ticket title). Correct as history; outside the done-when grep scope.
