# Rubric — Linguistic Potency

Scores the *language* of a prompt-carrying artifact (skill body, agent/system prompt, CLAUDE.md, tool schema, sub-agent dispatch, output contract) for how strongly it **instantiates** behavior vs. merely **describes** it. Provenance: authored 2026-07, maintained here as the pack's versioned standard; foundation + mechanisms in `resources/linguistic-techniques-for-agents.md`. `[gate]` = lint-checkable (`scripts/potency_lint.py`); `[review]` = judgment with cited evidence.

| # | Dimension | Type | What it checks | 1 (fail) → 3 (adequate) → 5 (excellent) |
|---|---|---|---|---|
| L1 | Instantiate over describe | [review] | Load-bearing behaviors are committed / presupposed / demonstrated, not merely stated | 1: prose describing the desired behavior · 3: mixed; key behaviors described · 5: every load-bearing line commits, presupposes, or demonstrates the behavior |
| L2 | Speech-act fit | [review] | Declaratives for identity, questions to force reasoning, imperatives last; modals at RFC force | 1: all imperative, act is hollow · 3: some declarative identity · 5: mood matched to the computation wanted; MUST/NEVER genuinely load-bearing |
| L3 | Affirmative framing | [gate] | Target behavior stated positively; `NEVER` reserved for ≤ 3 hard gates | 1: prohibition wall — primes each forbidden behavior · 3: mixed · 5: affirmative procedures + ≤ 3 budgeted gates |
| L4 | Presupposition hygiene | [review] | Intended presuppositions collapse the search space; none unverified or false | 1: a false presupposition builds in confident, fluent wrongness · 3: unaudited assumptions ride along · 5: presupposes only the known; every assumption audited |
| L5 | Structural slots | [review] | Open generation converted to slots/schema where the output has a shape | 1: prose spec of a structured output · 3: partial structure · 5: slots / typed grammar — illegal outputs are hard to reach |
| L6 | Salience budget | [gate] | ≤ 3 hard-emphasis markers; load-bearing quantities numeric, not vague | 1: emphasis inflation (many CAPS/CRITICAL/bold) or vague quantifiers on load-bearing dims · 3: some · 5: ≤ 3 markers, quantities numeric |
| L7 | Position | [review] | Identity first, task-critical constraints last (near the action), references in the middle; each load-bearing line frame-led — the operative imperative/priority/conditional word first | 1: constraints lost in the middle, lines open with filler ("It is important to…"), or trusts position zero at turn 40 · 3: partial placement; some buried openers · 5: U-shaped placement; load-bearing lines lead with their frame word; forced state echoes near the action |
| L8 | Naming & compression | [review] | Recurring procedures / bars / failures bound to handles, defined once | 1: re-describes the procedure at each use · 3: some naming · 5: handles defined once, invoked as cheap tokens; re-anchored when they scroll out |
| L9 | Agent surface & closure | [review] | Stopping predicate for ANY artifact with a completion state — the done/NOT-done close is enforced house practice, not agent-only; tool names as prompts, named failure branches, quarantined input (agent surfaces; those three alone are n/a for non-agents) | 1: "until done" + unnamed failures + raw untrusted input treated as instruction · 3: some present · 5: checkable predicate + branches + quarantine + intentional tool/param names |
| L10 | Register & demonstration | [review] | Prompt written in the target register; contrastive demonstration over prose criteria | 1: sloppy register, all description · 3: some · 5: register-matched; one good/bad pair binds quality, non-exemplary content labelled |

**Gate to promote:** **L1, L3, L6** each ≥ 3. L1 is the master criterion — an artifact whose language only *describes* fails the point regardless of the rest; L3 and L6 are the lint-backed floors (`scripts/potency_lint.py`).

**Fence grammar (routing descriptions):** when the artifact under audit is a skill/agent `description:`, only the `NOT for <thing> (<owner>)` family parses as a fence in the measurement layer — the measurement layer splits at the fence marker and turns the fenced vocabulary into a repellent. `NOT a <thing>` registers zero fenced tokens: a semantic fence invisible to measurement is not a fence (this pack's own routing campaign proved it).

**Top failures to look for first:** (1) fluent prose that *describes* the desired behavior (L1) — it reviews well and behaves weakly, the highest-cost class because it passes casual read; (2) a false presupposition (L4) absorbed silently into confident wrongness; (3) a prohibition wall (L3) that primes every behavior it forbids.
