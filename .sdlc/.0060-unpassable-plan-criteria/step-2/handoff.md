## Task goal
A plan criterion that cannot pass is caught before any build, and a plan defect goes to replan instead of a rebuild.

## Step 2: A plan defect routes to a replan, never to a rebuild or a level bump
level: L3
### Do
One tag, used everywhere: the literal prefix `plan defect:` as the first line of a blocked builder's `## Notes`, the first line of a failing verifier's `## For the next attempt`, or the last line of a `steps.py split` refusal. Whoever sees it runs planner L3 on the task handoff; it never triggers a rebuild, a level bump, or a `## Previous attempt` note.

- `plugins/sdlc-lite/agents/planner.md`: before the output format, add the rules under a short heading such as `Criteria that can pass`: (1) run each runnable criterion once on the current tree before writing it, read-only commands only, never one that changes the tree or git state: a criterion for the step's new behavior must be red now and red for the right reason (the behavior is missing, not a typo, a wrong path, or a command not found); a criterion that must hold before and after the step is tagged `(guard)` and must be green now; (2) every criterion of a step must be able to hold at once, and none may pin a moving target (never `solution == HEAD` next to `base == HEAD~1` when the step itself commits); (3) a lint, test suite, or checker over a whole file or repo passes only on "no new findings versus the base commit", stated as the same command in a `git worktree add <tmp> HEAD` copy or as a file-scoped invocation, unless the Do fixes the existing findings; (4) never put a deliberately broken command in a criterion code span, because `steps.py split` parses every command span: name a fixture or describe it in prose; (5) on a replan, read the handoff's `## Plan review` section, every `step-*/builder-*.md` with Status blocked, and every `step-*/verifier-*.md` whose For the next attempt starts with `plan defect:`, fix that criterion or step, and keep the numbers and text of steps that already passed so `steps.py split --only` can rewrite only the rest.
