## Task goal
Branches owned by an outside agent can join fanout without hand-made lane/<x> refs, and ticket ids created on such a branch cannot collide with tickets.py ids (register the owner or branch, or reserve id ranges).

## Step 2: fanout.py runs a registered external branch as a lane with no worktree and no driver
level: L4
### Read first
- `plugins/sdlc-lite/AGENTS.md`
### Do
Change only `plugins/sdlc-lite/scripts/fanout.py`.
1. Spec: `<lane>@<branch>=<id>[,<id>...]`. Parse each spec with `rpartition('=')` for the ids, then `partition('@')` on the left part for the branch. An empty branch (`alpha@=T-0001`) or no `=` (`alpha@x`) refuses with the usage text `want <lane>=<id>[,<id>...] or <lane>@<branch>=<id>[,<id>...]`. Lane name rules are unchanged. `Lane` gains `external` (the branch name, else `None`); for an external lane `lane.branch` is that branch and `lane.dir` is `None`.
2. Preflight (every refusal still prints on stderr, exits 2, creates nothing): the branch must be in `tickets.external_branches(root)`, else refuse with a message holding `external_branch: <branch>` and the path of `<root>/config`; `refs/heads/<branch>` must resolve to a commit; the branch must not equal the integration branch or any `<integration>-<lane>` of this run, and no two lanes may name one branch. The lane's tickets come from `tickets.branch_tickets(root, branch)` (they may exist only on that branch), with the same one-folder, not-done-or-dropped, once-across-all-lanes checks; a missing id refuses with `<id>: no ticket on branch <branch> has this id`. The lane-branch clash and `lane.dir` checks, the `check-ref-format` list, and the handoff-at-start check run for regular lanes only (an external ticket's handoff was read from the branch).
3. `print_plan`: `lane <name>: external branch <branch> (registered; no worktree, no driver)`, then its ticket lines as today. `setup` creates no worktree and no branch for an external lane, and its missing-handoff check covers regular lanes only.
4. `run_ticket`, external path: no pre-sync wip, no sync, no driver, no lane commit; go straight to the merge block under the lock: the integration-dirty refusal; `git merge --no-ff --no-edit -m "Merge <branch>: <id>" <branch>` in the integration worktree; a conflict is aborted (`merge conflict`); when HEAD is unchanged after the merge (the branch was already merged, as for the second ticket on one branch or a resume) the gates are skipped, else the gates run as today with the first red one resetting to the pre-merge commit; no `copytree` (there is no lane dir); then `tickets.py close <slug>` and the `close <id>` commit as today. Factor the merge-gate-close block into one helper both paths call rather than copying it. The outside branch is never written: no sync merge onto it, no ref update. `run_lane` skips `wip_commit` when `lane.dir` is `None`.
5. `report`: an external lane's line is `- Lane <name>: external branch <branch> at <sha>` (name, branch, and the full sha in backticks); rows as today.
6. Docstring (keep the words `inherited red`, which check.py requires), the usage line in `main()`, and the argparse metavar and help: the spec form, the registration rule, the preflight refusals, the per-ticket path, and the selftest cases below.
7. Selftest case 11 on a throwaway repo whose `.sdlc/config` holds `external_branch: ext` (committed on main), with branch `ext` made by `checkout -b`, given `.sdlc/b` (T-0002) and `.sdlc/c` (T-0003) each with a handoff and a `filer-L1.md` plus a file, then `checkout main`: a mixed run `alpha@ext=T-0002,T-0003 beta=T-0001` with the stub driver and `--gate true` exits 0, merges both lanes (two merge commits on the integration branch), closes a, b, and c there, leaves the `ext` tip and main unchanged, creates no `<integration>-alpha` ref and no `<lanes-dir>/alpha` dir, writes no `alpha-T-0002.log` driver log, one `gate-alpha-T-0002-1-a1.log` and no gate log for T-0003, and `report.md` holds the external lane line and both rows; `--dry-run` prints the plan line and creates nothing. Negative control: the same lane with the config line absent exits 2 naming `external_branch: ext` and `.sdlc/config`, with no `fanout/*` branch and no lanes dir. Refusals, each exit 2 creating nothing: `alpha@=T-0002`, `alpha@ext`, a registered name with no local ref, one branch in two lanes, an id absent on the branch. A `--gate false` run reports `red: false rc=1`, leaves the integration branch at its base and `ext` unchanged.
